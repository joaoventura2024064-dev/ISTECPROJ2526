Simulador Epidémico Interativo de Observação Sistémica

Projeto Interdisciplinar

1. Objetivos

Desenvolver uma plataforma Web robusta para modelação de vírus em populações reais com elevado grau de realismo.

  • Modelação Estocástica Avançada: Transição para uma abordagem probabilística que captura a variabilidade real dos surtos.
  • Experiência de Utilizador Premium: Interface intuitiva que democratiza o acesso a simulações complexas.
  • Gestão Integral de Dados: Sistema completo de persistência para guardar e comparar históricos.
  • Métricas em Tempo Real: Cálculo dinâmico do Rt (Número de Reprodução) para apoio à decisão.

2. Metodologia

Modelo SIR Estocástico

  • Aleatoriedade: Uso de distribuições Binomiais para transições de estado realistas.
  • Reprodutibilidade: Seeds controladas.

Segurança e Gestão

  • Autenticação: JWT e passwords cifradas (bcrypt).
  • Controlo de Acesso: RBAC (Admin vs User).
  • Exportação: Relatórios CSV para análise externa.

Tech Stack

React Flask MySQL NumPy JWT

3. Resultados

  • Visualização de Curvas Epidémicas.
  • Monitorização do Rt para análise de controlo do surto.
  • Painel de administração funcional para gestão de utilizadores.

4. Conclusões

  • Sucesso na implementação do motor estocástico.
  • Segurança robusta garante integridade dos dados.
  • Ferramenta educativa poderosa para análise de contágio.
